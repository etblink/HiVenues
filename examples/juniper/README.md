# Juniper starter

Juniper is an **illustrative, synthetic starter** for Hive-Venues. It is not a real venue, business, Hive community, or deployment.

Use it to see how the same generic Hive-Venues platform can support a venue that looks and reads very differently from the 4th Street Bar reference deployment. The starter demonstrates the venue-owned layer: name and business details, brand colors, logo and hero media, gallery media, homepage copy, programs, equipment/status content, and venue-specific onboarding language.

The shared application behavior remains platform-owned. Starting from Juniper should mean replacing venue content and media through the supported Venue Studio and deployment workflow—not renaming or forking platform source.

The companion `venue-source.json` is deployment-agnostic and intentionally uses reserved `.example` URLs plus synthetic Hive-style identifiers. The SVG media under `public/examples/juniper/` is illustrative artwork bundled solely for this starter.
